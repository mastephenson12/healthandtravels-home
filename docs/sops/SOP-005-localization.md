# SOP 005 — Localization

## Purpose
Create high-quality Spanish, Russian, German, and future localized Health & Travels content that preserves the meaning, usefulness, safety guidance, SEO intent, and customer journey of the original English page.

## Trigger
An English Health & Travels or Sage page is approved for localization into a supported language.

## Owner
Health & Travels Content Builder / Localization workflow.

## Inputs
- Approved English source page
- Target language
- Target URL pattern
- Existing localized navigation and templates
- Relevant localized Sage page, if available
- Current official sources for any time-sensitive claims

## Supported Languages
Current priority:
- Spanish
- Russian
- German

Add new languages only when there is a clear audience or search opportunity and the site can maintain them.

## Core Rule
Localization is not word-for-word translation.

The localized page must preserve:
- Meaning
- Safety intent
- Family usefulness
- Search intent
- Calls to action
- Brand voice

while reading naturally in the target language.

## Workflow
1. Start from the approved English source.
2. Identify any facts that may have changed since publication.
3. Re-verify time-sensitive details before localizing.
4. Translate and adapt headings naturally.
5. Preserve practical family-fit information.
6. Preserve safety warnings without softening them.
7. Adapt examples or wording only when it improves clarity for the target audience.
8. Create localized metadata.
9. Add localized internal links where available.
10. Connect to the localized Sage experience when one exists.
11. Preserve AHA CTA only when it makes sense for the page and audience.
12. Run a final language and layout review.

## SEO Requirements
Each localized page should have:
- Unique localized title tag
- Unique localized meta description
- Localized H1
- Clean language-specific URL
- Correct canonical strategy
- hreflang relationships when implemented
- Localized image alt text
- Internal links to same-language content where possible

Do not publish multiple languages under the same canonical URL.

## Translation Quality Rules
Avoid:
- Literal translations that sound machine-generated
- English idioms that do not make sense in the target language
- Translating proper place names incorrectly
- Inventing localized names for Arizona places
- Changing factual meaning for fluency

## Safety Content
Safety language receives extra review.

Do not:
- Weaken warnings
- Alter thresholds or official instructions
- Translate emergency terminology carelessly
- Assume the original safety facts are still current

Re-check official sources when the topic is time-sensitive.

## Destination Names
Keep official Arizona destination, trail, park, and business names in their recognized form unless an established translated form is appropriate.

## Images
Reuse approved images when rights allow.

Localize:
- Alt text
- Captions
- Supporting text

Do not create false localized firsthand claims.

## Sage Integration
Link to the matching target-language Sage page when available.

If no localized Sage experience exists, do not mislead the visitor. Use the best available planning path and make the language transition clear.

## AHA Integration
AHA is currently primarily an Arizona community product. Include it where relevant, but do not allow membership promotion to overwhelm the localized visitor's immediate need.

## Quality Check
Before publication verify:
- Language reads naturally
- Facts match the approved source or newer verified information
- Safety meaning is unchanged
- Place names are correct
- Links work
- Metadata is localized
- Mobile layout works
- No untranslated interface fragments remain unintentionally
- Sage destination is correct
- Canonical/hreflang setup is correct where implemented

## Output
A live localized Health & Travels or Sage page.
