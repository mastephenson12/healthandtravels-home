# Health & Travels / Sage / Arizona Hikers Association SOP Index

This is the operating map for the Health & Travels ecosystem.

## Customer Journey
**Discover → Plan → Subscribe → Join → Participate → Return**

## Core SOPs
1. **SOP 001 — Master Customer Journey** — defines how Health & Travels, Sage, newsletter, and AHA fit together.
2. **SOP 002 — Publish Health & Travels Page** — end-to-end page publishing process.
3. **SOP 003 — Destination Guide** — repeatable family destination-guide structure.
4. **SOP 004 — Safety Article** — sourcing, safety, review, and publication rules.
5. **SOP 005 — Localization** — Spanish/Russian/German and future language workflows.
6. **SOP 006 — SEO + Internal Linking** — search intent, metadata, canonicals, links, and funnel handoffs.
7. **SOP 007 — GitHub + Vercel Publishing** — deployment, QA, rollback, and production checks.
8. **SOP 008 — Photo + Cloudinary Management** — naming, rights, cataloging, optimization, and usage.
9. **SOP 009 — Beehiiv Newsletter** — newsletter planning, production, publishing, and tracking.
10. **SOP 010 — Sage Trip Planner** — planning logic, UX checks, itinerary output, and testing.
11. **SOP 011 — Email Capture + Starter Pack** — lead capture, delivery, welcome flow, and handoff.
12. **SOP 012 — AHA Membership Acquisition** — traffic, offer, checkout, and conversion.
13. **SOP 013 — AHA New Member Onboarding** — first-seven-day member experience.
14. **SOP 014 — AHA Community Engagement + Retention** — participation, re-engagement, and churn reduction.
15. **SOP 015 — AHA Events + Meetups** — planning, safety, promotion, and follow-up.
16. **SOP 016 — Affiliate Link Placement** — placement, disclosures, review, and optimization.
17. **SOP 017 — Analytics / GA4 / Search Console** — measurement and funnel tracking.
18. **SOP 018 — Weekly Site Health + Security** — recurring technical, indexing, conversion, and security review.
19. **SOP 019 — Monthly Revenue Review** — monthly business scorecard and priorities.
20. **SOP 020 — Social Content Repurposing** — turn source content into platform-specific distribution assets.

## What to Run When

### When publishing a new destination page
Use SOPs **002 → 003 → 006 → 008 → 007 → 017 → 020**.

### When publishing a safety page
Use SOPs **002 → 004 → 006 → 007 → 017 → 020**.

### When localizing a page
Use SOPs **005 → 006 → 007 → 017**.

### When sending a newsletter
Use SOPs **009 → 011 → 017 → 020**.

### When improving Sage
Use SOPs **010 → 007 → 017**.

### When acquiring or onboarding AHA members
Use SOPs **012 → 013 → 014 → 017**.

### When running an AHA event
Use SOPs **015 → 020 → 014**.

### Weekly
Run **SOP 018** and the master weekly checklist.

### Monthly
Run **SOP 019** and review the operating dashboard.

## Operating Rule
No recurring workflow should remain dependent on memory alone. If a repeated task changes materially, update the relevant SOP.
