# Health & Travels SOP Library

This folder contains the operating procedures for the Health & Travels ecosystem.

## Core system

The customer journey is:

**Explore on Health & Travels → Plan with Sage → Join Arizona Hikers Association → Return**

## SOP structure

Every SOP should use this format:

1. Purpose
2. Trigger
3. Owner
4. Inputs
5. Steps
6. Quality check
7. Output
8. Next step
9. Metrics
