# SOP 006 — SEO + Internal Linking

## Purpose
Make every Health & Travels page easier for search engines to understand, easier for people to navigate, and more useful inside the larger Health & Travels → Sage → Arizona Hikers Association ecosystem.

## Trigger
Use this SOP whenever a new page is created, an existing page is substantially updated, or a content cluster is expanded.

## Owner
Health & Travels Content / SEO Operator.

## Inputs
- Final page topic
- Primary search intent
- Target keyword or query family
- Related Health & Travels pages
- Relevant Sage destination or planner route
- Relevant AHA membership/community path
- Current Search Console data when available

## Process

### 1. Confirm Search Intent
Identify what the visitor is actually trying to accomplish.

Common intents:
- Learn about a destination
- Decide whether a hike is appropriate for children
- Plan a weekend trip
- Check safety conditions
- Find food or lodging after an outdoor activity
- Compare Arizona destinations
- Build a personalized itinerary

Write for the intent first. Do not force a keyword into content that answers a different question.

### 2. Assign a Primary Topic
Each page should have one clear primary topic.

Avoid creating multiple pages that compete for the same exact search intent unless there is a deliberate parent/child content structure.

### 3. Write the SEO Elements
Each page should include:
- Unique title tag
- Unique meta description
- Canonical URL
- One clear H1
- Logical H2/H3 structure
- Descriptive image alt text
- Open Graph title/description when appropriate
- Article, FAQ, Breadcrumb, or other schema only when the page genuinely supports it

### 4. Use Natural Topic Coverage
Include related terms naturally when useful, such as:
- Family-friendly
- Difficulty
- Shade
- Bathrooms
- Parking
- Season
- Heat
- Water
- Stroller access
- Elevation
- Trail conditions
- Nearby food
- Nearby lodging

Do not keyword-stuff. Search engines remain tragically unimpressed by prose written like a malfunctioning tag cloud.

### 5. Add Internal Links Into the New Page
Every substantial page should link to relevant pages in at least these categories when they exist:
- Parent destination hub
- Related destination or trail guide
- Relevant safety guide
- Relevant checklist
- Sage planning page
- Newsletter or lead magnet when useful
- Arizona Hikers Association when the community offer is a logical next step

Use descriptive anchor text. Avoid generic anchors such as "click here" when a useful description is possible.

### 6. Add Internal Links From Existing Pages
Find at least 2 to 5 existing relevant pages that can link to the new page.

Prioritize:
1. High-traffic pages
2. Strongly related topic pages
3. Parent destination hubs
4. Safety or checklist pages
5. Language-equivalent pages when relevant

Do not create links simply to hit a quota.

### 7. Protect the Customer Journey
Internal links should support the desired path:

Explore → Learn → Plan with Sage → Subscribe / Join → Return

Do not interrupt useful editorial content with excessive promotion.

### 8. Review URL Structure
URLs should be:
- Short enough to read
- Descriptive
- Lowercase
- Hyphen-separated
- Stable

Avoid changing an indexed URL without a redirect plan.

### 9. Check Canonicals and Localization
For translated pages:
- Self-canonicalize each language page unless there is a specific technical reason not to
- Use correct hreflang relationships when implemented
- Include x-default when appropriate
- Do not canonicalize all translated pages back to English, which would rather efficiently tell Google to ignore the localization work

### 10. Update Sitemap When Required
Ensure the page is included in the correct sitemap or route generation system.

Do not place intentionally non-indexable pages in the sitemap.

### 11. Search Console Follow-Up
After publishing:
- Confirm the page is crawlable
- Inspect the URL when necessary
- Watch impressions, clicks, average position, and query growth
- Look for cannibalization or unexpected duplicate indexing

### 12. Refresh Existing Pages
Use Search Console data to improve pages receiving impressions but weak clicks or ranking.

Potential improvements:
- Better title
- Better opening answer
- Stronger internal links
- More useful family-fit information
- Updated safety details
- Original photos
- FAQ expansion
- Better Sage next step

## Quality Check
Before considering SEO complete, verify:
- Search intent is clear
- Title and description are unique
- Canonical is correct
- H1 is unique
- No accidental noindex
- Internal links work
- Sage link works
- AHA link is contextually appropriate
- Images have useful alt text
- Sitemap behavior is correct
- No duplicate page was created unnecessarily

## Output
A crawlable, internally connected page that strengthens both organic discovery and the Health & Travels user journey.

## Metrics
- Search impressions
- Organic clicks
- CTR
- Ranking queries
- Internal-link clicks
- Sage referrals
- Newsletter conversions
- AHA referrals
