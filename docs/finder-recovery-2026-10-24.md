# Helpful empty results — October 24, 2026

Empty finder searches now offer specific, optional changes rather than requiring visitors to guess. Up to three choices each change one field: an activity with matches, the smallest useful drive increase, or the smallest useful time increase. Each states the resulting shortlist count. Other answers, including the starting area, group and comfort/food needs, are retained. Matching still applies the existing hard activity, drive and minimum-time filters; unknown routes stay excluded.

The change is applied only after clicking a button, followed by the normal form submission and remembered-choice flow. Suggestions are rechecked against current form values before applying, so stale buttons cannot overwrite updated answers. On restoring an empty search, suggestions are recalculated. If no single change helps, the interface explains that and keeps guide and Sage links available. Facility/route facts and scoring are unchanged.
